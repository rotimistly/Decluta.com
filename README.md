# Decluta.com

A marketplace for buying and selling used and new items across Nigeria.

## Features
- All 36 states + FCT, with state and category filters
- ID + face-verified sellers with a blue tick
- Safe Pay with pickup code, refunds and delivery to other states
- Wanted board, saved items, alerts, in-app chat and swaps
- Reviews, Top Seller badge, seller shops, boosts and levels
- Referral credit, cashback and a demo admin page

## Status
Prototype. Payments, ID and face verification, and accounts are simulated and stored only in the browser. A real backend (database, Paystack, an ID verification provider) is the next step.

## Run it
Open `index.html` in a browser. No build step.

## Before launch
- Replace `SITE_URL` in `index.html` with your real domain.
- Have a Nigerian lawyer review the Terms, Privacy and Refund pages.
